# Porsche Designer Project

## Overview
This project is aimed at creating a design representation of Porsche vehicles using modern design tools and methodologies.

## Features
- Interactive 3D models
- High-resolution images
- Design documentation

## Getting Started
1. Clone the repository
   ```bash
   git clone https://github.com/matteo521/porsche-designer.git
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Run the application
   ```bash
   npm start
   ```
